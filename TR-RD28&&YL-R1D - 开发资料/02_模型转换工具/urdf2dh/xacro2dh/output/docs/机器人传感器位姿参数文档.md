# 机器人传感器位姿参数文档

**机器人**：`ylr1d`  

**生成工具**：`xacro2dh`  

**源文件**：`../urdf/ylr1d.xacro`、`../config`  

**参考坐标系**：`Link_Base`（基座系）  



**说明**：  

- `mount.transform` 为常量变换 `T_{parent_link -> sensor}`，即传感器相对于父连杆的固定位姿（来自 URDF 固定关节）。  

- `pose_base` 为零位形（所有关节 `q=0`）下传感器相对于 `Link_Base` 的位姿 `T_{base_frame -> sensor}`。  

- 对于挂载在 DH 运动链末端的传感器（`chain` 非空），在任意关节状态 `q` 下，传感器实际位姿为：

`T_Base^sensor(q) = T_Base^{chain_base}(q) · DH_FK(chain, q) · mount.transform`

其中 `T_Base^{chain_base}(q)` 为链基座相对于基座的位姿（若链基座不是 `Link_Base`，则需包含中间变换），具体参考运动学文档中的链 FK。  

- 对于直接固定在基座上的传感器（`chain: null`），其位姿不随关节运动变化，等于 `pose_base`。
